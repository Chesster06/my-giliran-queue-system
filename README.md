# MyGiliran

> **One Scan, One Turn.**  
> A lightweight, zero-app QR queue management system.

---

## Overview

**MyGiliran** is a modern, fast, and frictionless queue management web application. Customers simply scan the counter QR code using any smartphone camera, enter their name, and receive their digital queue ticket instantly with live turn updates — no app downloads or registrations required.

---

## Key Features

- **Zero App Download:** Works directly in any mobile browser (iOS & Android).
- **Instant QR Code Generation:** Generate unique counter QR codes for acrylic stands or digital screens.
- **Pure Frontend:** Ultra-lightweight, blazing fast (<150ms build time), and low data usage.
- **Live Queue Tracking:** Real-time customer position updates and queue numbers.

---

## Tech Stack

- **Framework:** React 19
- **Bundler:** Vite 8
- **Smooth Scroll:** Lenis
- **QR Engine:** QRCode

## Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or pnpm

### Installation

```bash
# Clone repository
git clone https://github.com/Chesster06/my-giliran-queue-system.git

# Navigate to directory
cd my-giliran-github

# Install dependencies
npm install
```

### Running Locally

```bash
# Start Vite development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Building for Production

```bash
npm run build
```
